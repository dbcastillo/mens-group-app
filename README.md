# Men's Group App

A mobile-responsive community web application designed to encourage connection and meaningful relationships among men.

## Project Overview

This project explores how technology can facilitate community building and social engagement through an accessible, mobile-friendly interface.

## Technologies

- Next.js
- React
- JavaScript
- ESLint

## Getting Started

Install dependencies:

    npm install

Start the development server:

    npm run dev

Open http://localhost:3000 in your browser.
